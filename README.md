# Counterform Studio

A modular, local-first HTML/JavaScript font-authoring studio built with SkiaSharpWeb, Dockyard, TreeDataGridWeb, DynamicDataWeb, RibbonWeb, ReactiveWeb, RBushWeb, QuikGraphWeb, GridWeb and RichTextWeb.

This repository is being populated from the delivered Counterform Studio source package. Implementation and verification status are recorded in `docs/CAPABILITIES.md`; no full FontLab feature-parity claim is made.
